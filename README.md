# Portfolio Website 2.0

Personal portfolio site — modern redesign with CSS Grid, vanilla JavaScript, and the VinciVision brand system. Multi-page static site featuring case studies across software development, video production, AI app development, and creative work.

**Live site:** [arieeskinazi.com](https://arieeskinazi.com)

## What's in here

- Static multi-page site (HTML, CSS, vanilla JS)
- 25+ portfolio case-study pages spanning: AI app development (Savora), video production (Versace, Suculenta, Daily Routine, Cicatrize, KGarcia Reel, Deep In Love, While Dreaming, No Bullying), C# / C++ / Python / HTML-CSS-JS coursework, game development (Catacomb Quest, Classic Arcade), database / SQL projects, e-commerce work, and more
- VinciVision brand system applied across navigation, typography, and color
- PHP contact form

## Stack

HTML5 · CSS3 (Grid + Flexbox) · vanilla JavaScript · PHP (contact form)

## Structure

- `index.html` — landing
- `AppDevelopment_webpage.html`, `SoftwareDevelopment_webpage.html`, `VideoProduction_webpage.html`, `VideoGames_webpage.html` — category landing pages
- Individual portfolio pages: `SavoraAIPort.html`, `SavoraPort.html`, `CatacombQuestPort.html`, `ArcadeGamePort.html`, `VersacePort.html`, etc.
- `Images/`, `PDFs/`, `js/`, `styles/` — assets
